## 限制

- 資料與規則出自同一個設計者。滿分代表規則確實照 policy.yaml 執行、同步與身分對應沒有遺漏，不代表在真實公司也能全對：真實資料會有規則沒想到的例外。
- 同儕離群是統計判斷，同一組同事裡有多個離群者時會互相稀釋；門檻調高會漏抓、調低會多報（調參紀錄見種子 1–10 的結果）。
- GitHub 帳號對不上登記表時一律只建議「確認身分」，不建議直接移除。
